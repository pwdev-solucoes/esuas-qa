CA06 — tipo de deficiencia para integrante SEM a marcacao (has_disability = false)
----------------------------------------------------------------------------------

body: {"disability_type_uuid": "849e751c-..." (5 — Deficiencia fisica)}
HTTP 422
{
  "message": "O tipo de deficiência só pode ser informado para integrante com deficiência registrada na composição familiar.",
  "errors": {
    "disability_type_uuid": [
      "O tipo de deficiência só pode ser informado para integrante com deficiência registrada na composição familiar."
    ]
  }
}

422 com a mensagem da chave `disability_type_not_applicable`
(lang/pt_BR/family_member_condition.php). A marcacao de deficiencia nao e
ligada pelo payload: ela vem da composicao familiar.
